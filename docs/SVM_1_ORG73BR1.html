Information

The purpose of this screen was to develop an image-based classification to characterize dead or alive organoids in addition to standard CTG analyses
We address organoid heterogeneity by creating an image-based signature for independent quantification of spheroids killed by cancer drugs.

The readouts from the high-content image analysis include morphology, intensity, and texture features of the spheroids in BF and Hoechst live-cell images.

Conditions

  • Alive/ healthy control (Vehicle control Wells from patient ORG73BR1)
  • Dead organoids (high dose drug control Wells)
  • Unknown phenotypes (all other Wells)


Instrument

Cytation 10 (1 field @ 4X magnification)

Compound Classes

The following classes (bins) were assigned to Wells averages in control Wells:

  • 1. Controls with healthy/alive phenotype
  • 2. Controls with dead phenotype
  • 3. Unknown Wells (all other Wells)

Tuning SVM

The kernel argument has a variety of possible types including linear, polynomial, radial, and sigmoid. We use kernel=”radial” for this classification problem. You can tune the operation of svm() with two additional arguments: gamma and cost, where gamma is the argument for use by the kernel function, and cost allows us to specify the cost of a violation to the margin. When cost is small, the margins will be wide, resulting in many support vectors. You can experiment with different values of gamma and cost to find the best classification accuracy.

Here, changing cost from 1 to 5 and keep gamma at default improved the model performance from 98% to 99% accuracy.

# Define new values for gamma and cost
new_gamma <- 0.01
new_cost <- 5

# Create the SVM model with the new gamma and cost values
svm_model_after_tune = svm(Bin ~ ., data = trainTransformed, kernel = "radial", gamma = default_gamma,
    cost = new_cost, probability = TRUE)

summary(svm_model_after_tune)
